# Synergy_python

Репозиторий с домашними заданиями по дисциплине "Стек технологий Python".

## 📚 О курсе

Университет: Синергия  
Направление: Fullstack-разработка

## 📂 Структура репозитория

Каждое домашнее задание находится в отдельной ветке.

Пример:

- lesson_3
- lesson_4
- lesson_5

## 🚀 Как посмотреть задания

1. Открой список веток (branches)
2. Выбери нужную ветку (например, `lesson_3`)
3. Посмотри файлы внутри

## 🎯 Цель

Практика Python и закрепление знаний.
